/* The admin plugin's stylesheet, a part tagged $:/tags/Stylesheet (design 2.21): where TiddlyWiki's
   theme doesn't fit the modules' markup. Plain CSS: a text/css tiddler isn't wikified, so no palette
   macro here; the colours below read on light and dark backgrounds, and never say anything alone. */

/* The cloud icon's dropdown: the theme gives a dropdown a 380 px minimum width and no wrapping, and
   makes every link in it a block of its own; the outbox's item is sentences, with links in them */
.tc-drop-down .cfworker-outbox {
	white-space: normal;
	max-width: 22em;
	padding-right: 14px;
}
.tc-drop-down .cfworker-outbox a,
.tc-drop-down .cfworker-outbox a.tc-tiddlylink,
.tc-drop-down .cfworker-outbox a.tc-tiddlylink-external {
	display: inline;
	padding: 0;
	width: auto;
}

}

}

/* An alert's close button (TiddlyWiki's, the icon alone, 14 × 17 px): a thumb's hit area on a
