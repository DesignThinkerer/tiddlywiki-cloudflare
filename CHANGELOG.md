# Changelog

What changed, and what an update asks of you, newest first. Your worker is deployed from your copy of this repository: an update is GitHub's *Sync fork* ([operating 3.1](docs/operating.md#31-updating-your-copy)), and Workers Builds redeploys. Unless an entry says otherwise, nothing else is needed. Each dated block is a release: its date is the version the admin wiki shows for the worker's plugin (`2026.10.19` for 2026-10-19), and the tag `v2026.10.19` on GitHub's Releases page carries the block as its notes. From the next release on, each dated block opens with **What this asks of you:** and the asks by whom they concern (a fork, a wiki set up by hand, everyone), or "Nothing"; a security fix's entry starts with **Security:**; test-only and docs-only entries close the block in a short list. To be told of each release by e-mail: *Watch → Custom → Releases* on this repository (DesignThinkerer/tiddlywiki-cloudflare, not your fork), or follow its [releases feed](https://github.com/DesignThinkerer/tiddlywiki-cloudflare/releases.atom). The history before the repository went public is in git.
